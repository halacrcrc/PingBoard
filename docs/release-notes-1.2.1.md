# v1.2.1 发布说明 —— 拖拽归入文件夹 + 三区域宽度可调

> 对比基准：v1.2.0（tag `v1.2.0`）
> 文件夹设计见 [`folder-design.md`](folder-design.md)；前一版差异见 [`release-notes-1.2.0.md`](release-notes-1.2.0.md)

---

## 一、这次解决什么问题

v1.2.0 有了文件夹，但**整理归属仍然只能靠添加时选一次**：

1. **加完之后就没法改归属。** 想把几台已经加好的机器从临时区挪进「机房A」，
   只能删掉重加 —— 统计与事件日志跟着一起没了。
2. **三块区域宽度固定死。** 文件夹名长的用户嫌侧边栏窄，看事件日志的嫌详情区窄，
   而主表被挤得只剩几列可见。

v1.2.1 补上这两件事，并把「判重」的口径改成用户实际需要的形状。

## 二、新增功能

### 2.1 拖拽归入文件夹

在主表按住任意一行，拖到左侧文件夹（或「临时区」）即完成归属调整。

| 细节 | 行为 |
|---|---|
| 拖哪些 | 拖的那一行**若已在选中范围内**，则**整批一起移动**；否则只移动该行 |
| 激活阈值 | 按下后**位移超过 5px** 才进入拖拽态 —— 正常点击不会被误判成拖动 |
| 拖到「临时区」 | 等于**移出文件夹**（回到未分类区） |
| 落点反馈 | 悬停的文件夹行高亮 |
| 浮层坐标 | 按当前界面缩放因子换算，缩放 125% 时拖影仍跟随指针 |

### 2.2 右键归入（等价通道）

表格行右键 →「**移动 N 台主机到**」→ 选目标文件夹。

> 🩸 这不是锦上添花：WebView2 + `<table>` 下 **HTML5 原生拖放在本项目中根本不触发**
> （`dragstart` 不派发，`dragover` 自然也不执行，表现为「拖过去毫无反应」）。
> 因此拖拽最终改为**鼠标事件自实现**，同时保留右键菜单作为独立通道 ——
> 任何一条链路失效都不会导致「无法调整归属」。

### 2.3 三区域宽度可拖动

文件夹区、Ping 主表区、主机详情区之间各有一条分隔条：

| 项 | 值 |
|---|---|
| 文件夹区 | **120 – 480 px**，默认 **192** |
| 详情区 | **280 – 720 px**，默认 **420** |
| 主表 | 不直接拖，但**始终保留 ≥ 320 px**（被两侧挤压时钳制） |
| 恢复默认 | **双击分隔条** |
| 持久化 | 宽度写入 `localStorage`，下次启动保持 |
| 默认观感 | 与 v1.2.0 完全一致，不动手就看不出版式变化 |

## 三、行为变更（⚠️ 需要留意）

### 3.1 判重范围：全局 → 同文件夹内

| | v1.2.0 | v1.2.1 |
|---|---|---|
| 同一文件夹内重复 IP | 拦截 | **拦截**（不变） |
| 不同文件夹出现相同 IP | **拦截** | **放行** |
| 临时区内部 | 拦截 | **拦截**（`null` 与 `0` 视为同一组） |

**为什么改**：同一台机器常需要在多个分组各记一份（例如「机房A」与「重点观察」）。
旧口径下只要 A 文件夹已有 `1.1.1.1`，B 文件夹就再也加不进去。

> 判重**只在前端 UI 拦截**，后端 `add_targets` 本就不做判重，因此不影响既有配置的加载。

## 四、修正

| # | 问题 | 根因 |
|---|---|---|
| 1 | 拖 IP 到文件夹**毫无反应**（无拖影、无落点高亮） | 原生 DnD 的 `dragover` 未 `preventDefault` → `drop` 永不触发；深层原因是 `dragstart` 在 WebView2 表格行上根本不派发 |
| 2 | 分隔条几乎看不见，且与侧边栏边框并排，分不清哪条能拖 | 分隔条加宽（4px → 6px）、加深色阶，并移除侧边栏自身的右边框 |
| 3 | 拖影 / 右键菜单在 125% 缩放下位置偏移 | 浮层定位未除以 `currentZoomFactor()` |

> 🩸 **教训（已写入 `docs/HANDOFF.md`）**：这两轮失效的全是 **DOM 事件链路**，
> 而当时只补了纯函数测试（`dragMoveIds`、`clampPaneWidth` 全绿）。
> 纯函数测试对「事件根本不触发」完全无能为力 —— 这类交互必须实际点一次。

## 五、兼容性

| 项 | 结论 |
|---|---|
| 配置文件结构 | **无变化**，v1.2.0 配置直接可用 |
| 主机列表 / 文件夹 | **不受影响** |
| 多 ping 统计 | **不受影响**（统计文件结构未变） |
| 导出格式 | **完全不变**（CSV 仍 15 列） |
| 判重口径 | ⚠️ **行为变更**，见 §3.1 |
| 分隔条宽度存储 | 新增 `localStorage` 键（`pb-pane-sidebar` / `pb-pane-detail`），首次启动取默认值 |

### 升级建议

直接覆盖安装即可。若在 v1.2.0 里因为判重拦住了「同一 IP 放进多个文件夹」，
升级后可以正常添加了。

## 八、已知限制

- **ARM64 包未经真机测试**，属实验性质。
- 拖拽在极窄窗口（主表被压到 320px 附近）时命中区域变小，建议此时用右键菜单。
- 文件夹仍不支持嵌套（与 v1.2.0 一致）。
