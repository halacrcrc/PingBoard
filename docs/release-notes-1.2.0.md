> 对比基准：v1.1.9（tag `v1.1.9`）

## 一、这次解决什么问题

v1.1.9 把「导出报表」和「配置韧性」做扎实了，但有两件事一直悬着：

1. **主机列表是「一锅粥」。** 几百台机器平铺在一张表里，只能靠搜索框临时过滤。
   关掉搜索框，顺序就乱了；想找「机房 A 的机器」，每次都得重新搜一遍。
2. **多 ping 数据活不过一次会话。** 早上发现某段线路抖得厉害，想下午对比一下 ——
   关掉应用再打开，统计归零。丢包趋势、延迟曲线全部要重新攒。

v1.2.0 一次性解决这两件事，并新增 Shift 连续选择与多处修正。

## 二、新增功能

### 2.1 主机文件夹

左侧新增可折叠侧边栏，把主机按 **机房 / 区域 / 用途** 分组管理。

| 能力 | 说明 |
|---|---|
| 创建 / 重命名 / 删除文件夹 | 侧边栏操作，删除文件夹会连带删掉里面的主机（**有二次确认**） |
| 12 种颜色标记 | 未识别或缺失的 `color` 一律降级为灰色，**不报错** |
| **多选** | 可同时勾选多个文件夹；🩸 **一个都不勾 = 不显示任何主机**（初始即空白，勾什么显示什么） |
| 添加时直接归入 | 新增 / 批量粘贴 / 文件导入三个入口都有「归入」下拉，带各文件夹当前台数 |
| 点击即筛选 | 点文件夹名即筛选表格；再次点击取消 |

### 2.2 统计持久化

**关闭应用再打开，多 ping 数据默认保留。**

- 统计单独存文件，**升级应用、改配置都不影响**；
- 存的是完整历史（含延迟趋势曲线），不是只存累计值；
- 「清空统计」会同时删除持久化文件 —— 否则重启后旧数据会复活。

### 2.3 导出范围跟随侧边栏

在侧边栏选中「机房 A」再导出，对话框里的「全部节点」导出的就是机房 A，
而不是全局全部。🩸 **未勾选任何文件夹时导出 0 台** —— 这与侧边栏
「一个都不勾 = 都不显示」是同一口径，导出内容与屏幕上看到的保持一致。

## 三、行为变更（⚠️ 需要留意）

### 3.1 「清空列表」改为只清临时区

这是本次**唯一一处破坏性行为变更**，也是最需要说清楚的一条。

| | v1.1.9 | v1.2.0 |
|---|---|---|
| 「清空列表」删除范围 | **全部**主机 | **仅临时区**（未归入任何文件夹的） |
| 文件夹内的 IP | 一并删除 | **不受影响** |
| 确认框 | 「确定要删除全部 N 个目标吗？」 | 「删除临时区的 N 个…文件夹内的 M 个 IP 不受影响」 |

**为什么改**：有了文件夹后，用户花时间整理好的清单不该被一个「清空列表」抹掉。

**要删文件夹内的主机怎么办？** 用侧边栏的「删除文件夹」（有二次确认，会告知连带删除几台）。

临时区台数为 0 时，按钮不再弹出确认框（避免「删除 0 台」的怪异弹窗）。

### 3.2 搜索关键词不参与导出范围

导出只跟随**侧边栏勾选**，不跟随搜索框里的关键词。
搜索是瞬时的视图过滤，文件夹才是结构性的归属 —— 输错一个字不该悄悄改变导出内容。

## 五、兼容性

| 项 | 结论 |
|---|---|
| 配置文件结构 | **向后兼容**，旧配置可直接用；新字段缺失时降级为默认值，**不报错** |
| 主机列表 | **不受影响** —— 升级不会丢任何主机 |
| 多 ping 统计 | 升级后**从零开始**（旧版本没存过），此后正常保留 |
| 导出格式 | **字段结构完全不变** —— CSV 仍固定 15 列，筛选只改行集合；既有 Excel 模板与解析脚本无需改动 |
| 原有导出行为 | 不筛选、未勾选文件夹时，产出与 v1.1.9 **逐字节一致** |
| 「清空列表」 | ⚠️ **行为变更**，见 §3.1 |

### 升级建议

直接覆盖安装即可，无需任何配置迁移。
如果你在 v1.1.9 里依赖「清空列表」一键删除全部主机，请改用侧边栏的「删除文件夹」。

## 八、已知限制

- **ARM64 包未经真机测试**，属实验性质。
- **统计文件不随配置迁移** —— 若手工删除配置文件，统计会一并清空。
- **文件夹不支持嵌套**（不能把文件夹放进另一个文件夹），这是有意的设计约束。
