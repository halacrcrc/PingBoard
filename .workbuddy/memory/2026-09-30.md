## 🔴 环境新坑：git push 走沙箱代理会失败（**比 SSH 超时更常见的那条**）
`git push https://github.com/...` 报
`Failed to connect to github.com:443 over proxy 127.0.0.1 after 2047 ms: Could not connect to server`。
**解法（实测有效）**：
```
NO_PROXY='*' no_proxy='*' git -c http.proxy= -c https.proxy= push https://github.com/halacrcrc/PingBoard.git main
```
推完照样要 fetch 修正跟踪（同样带这套前缀）：
```
NO_PROXY='*' no_proxy='*' git -c http.proxy= -c https.proxy= fetch https://github.com/halacrcrc/PingBoard.git main:refs/remotes/origin/main
```
⚠️ 光设 `NO_PROXY` 不够，必须**同时**用 `-c http.proxy= -c https.proxy=` 把 git 自己的代理配置清空
（本机 git 配置里有 proxy，优先级高于环境变量）。
优先级顺序：先试 SSH → 不通则 HTTPS → HTTPS 也报代理错就用上面这条。
