### 🩸 新教训：彩色行底会把本来达标的色阶拉回线下（v1.1.6 核心发现）
主机列表的 `tr` 底色随状态变化（`bg-emerald-50` / `bg-red-50` / `bg-sky-50` / `bg-slate-50`），
**全部比白底更暗**，于是「白底刚好达标」的档位会掉线：
| 色 | 白底 | 落在 `red-50` 失败行底 |
|---|---|---|
| `slate-500` | 4.76:1 | **4.35:1** ❌ |
| `red-600` | 4.83:1 | **4.41:1** ❌ |

→ **表格内文本色阶必须按「最暗行底」设计，不能按白底**。具体落地：
`TargetTable` 全表 `slate-500` → **`slate-600`**（占位 `-`、`/` 分隔符、「最后成功时间」）、
`red-600` → **`red-700`**（失败计数）；`rttColorClass(null)` 也必须是 **`slate-600`**（该函数**只服务表格**）。
🩸 **漏网点**：v1.1.6 第一轮只改了表格里的 `text-slate-500` 字面，**延迟列的占位 `-` 走的是
`rttColorClass` 的 null 分支**（仍是 `slate-500`）→ 照样 4.35:1。**改 token 时务必回溯「同义分支」**。
守护测试：`tests/frontend_pure.test.mjs` 断言 `rttColorClass` 六组映射 + 占位**不得**含 `text-slate-500`。

### 空值 / 零值语义（v1.1.6 已修）
原则：**无数据不得画成「正常」，0 次失败不得画成「故障」**。
- `DetailPanel` 的「最近延迟」：`accent={Number.isFinite(target.last_rtt_ms) ? "text-emerald-700 dark:text-emerald-400" : undefined}`
  （原硬编码 `emerald-600` → 值为空显示 `-` 时也是绿的）。
- `DetailPanel` 的「失败」：`accent={target.failed > 0 ? "text-red-600 dark:text-red-400" : undefined}`（与「丢包率」同规则）。

## 设置对话框（`SettingsDialog.tsx`）
- 🩸 **「界面与行为」卡（v1.1.7-dev）新增两下拉（并排一行）**：「界面缩放」（`ui_scale`，90/100（默认）/110/125，
  手改过的旧值自动追加为选项）与「界面字体」（`ui_font_family`，系统默认 + `list_system_fonts()` 懒加载枚举，
  枚举失败只剩「系统默认」；当前族名已卸载时追加保留防丢配置）。zoom 实现与 `currentZoomFactor()` 坑见主记忆 UI 铁律。
- 900px 宽、正文**双列卡片网格**，4 卡 `探测`（跨列，内三列）/ `界面与行为` / `并发` / `事件日志`（跨列）；
  **标题区与底部操作栏也是卡片**；输入框 / 小按钮统一 **`h-8`**。
- **✕ 贴弹窗右上角**（距上 2.8px / 距右 6.8px），**刻意不与卡片右缘对齐**；**SVG 自绘**
  （viewBox 16、`w-3.5`、`strokeWidth=2.2` → 实测 1.925px）—— 字体符号 `✕` 粗细跨机不可控，要加粗必须自绘。
  🩸 **「只动 ✕ 不动版式」：改 `pt` 的同时补等量 `mb`**，二者之和不变 → ✕ 单独位移，其余分毫不动。
- 🩸 **右边缘对齐靠固定滚动条宽度**：滚动区 `[&::-webkit-scrollbar]:w-3`(12px) + `[scrollbar-gutter:stable]`，
  标题区 / 底部区 `pr-6`(=12+12) 补位。**有 / 无滚动条两种状态都要测；量 delta 只比整宽卡。**
  ⚠️ 补位**不能挂在顶部容器**上，否则 ✕ 被它挡住、永远到不了弹窗右边缘（改用标题卡 `mr-6` 承接）。
- `max-h-[calc(100vh_-_2rem)]`（**不是 86vh**）→ 默认窗口**免滚动看全**；验收式
  `scrollHeight ≤ clientHeight + 1` 且最后字段输入框 `bottom` < 滚动区 `bottom`。
- 事件日志卡用 **`Block` 成组块**（标签在上 / 控件在下）；**不做「标签最左+提示最右」**（宽卡中间会拉出大片空白）。
- 高度账：「标签在上控件在下」每字段 **71px**、「标签在左」只要 **40px** —— 改版式前先算
  （第一版单列 1064px → 改双列才压到 676px）。
- ⚠️ 滚动区 grid 的 `children` 含「并发」那段整宽说明（标题为空）→ **按 index 取「事件日志」会错位**，
  必须按 `h3` 文本定位卡片；写断言前先 dump 结构，否则容易写出「取到空数组仍 PASS」的空断言。
